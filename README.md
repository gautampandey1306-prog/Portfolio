# Gautam Kumar Pandey | Portfolio

Personal portfolio site: strategy and transformation across maritime, energy and industry.

A static site with no build step: `index.html`, `styles.css`, `script.js` and the `assets/` folder.

## View locally

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8080
```

Then go to http://localhost:8080.
